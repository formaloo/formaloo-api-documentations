Creates the HubSpot configuration for a form.

Connect HubSpot and discover its object properties first. In `mapped_fields`, group mappings by supported HubSpot object type; every item needs a saved Formaloo `source_field` slug and the corresponding discovered `destination_field`. `sync_previous_responses` queues historical submissions, while `source_tracking` adds submission-source data.

A form can have only one HubSpot integration for the current user.
